### **NoScamSquad** — UPI Fraud Detection System

![Status](https://img.shields.io/badge/Status-Active-brightgreen?style=flat-square)
![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![LightGBM](https://img.shields.io/badge/LightGBM-2B2B2B?style=flat-square&logo=lightgbm&logoColor=white)
![ML](https://img.shields.io/badge/Machine%20Learning-FF6F00?style=flat-square)

A hybrid machine learning pipeline that detects UPI fraud in real-time using **LightGBM**, **Isolation Forest**, and a **rule-based engine**. The system classifies transactions into ALLOW / REVIEW / BLOCK with explainable risk scoring and a feedback-driven learning loop for continuous model improvement.

**Impact:** Engineered feature extraction from transaction behavior, device signals, and risk patterns — creating a system that adapts and improves with every decision.


![Status](https://img.shields.io/badge/Status-Complete-brightgreen?style=flat-square)

A decentralized supply chain system built on **Ethereum** that tracks agricultural produce from farm to consumer. Smart contracts enforce transparency, immutability, and tamper-proof record keeping — enabling end-to-end traceability that improves trust and verification.
